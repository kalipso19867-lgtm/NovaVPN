# Spider AI

Веб-приложение и Android WebView-оболочка.

## Возможности
- Чат-интерфейс на русском языке.
- Краткая история текущего сеанса.
- PWA manifest и Service Worker для веб-установки и кэширования оболочки.
- Android APK собирается GitHub Actions.

## Важно
Ответы запрашиваются у внешнего сервиса Pollinations через интернет. Проект не содержит встроенной модели, не работает автономно как ИИ, а доступность, условия использования и лимиты стороннего сервиса могут меняться. Не отправляйте конфиденциальные данные.

## Сборка APK
Откройте GitHub → Actions → Build Spider AI APK → Run workflow. После завершения скачайте артефакт SpiderAI-Android. Внутри будут APK и ZIP исходников.
