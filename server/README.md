# NovaVPN — собственный сервер VLESS + REALITY

Этот каталог разворачивает личный VPN-сервер sing-box на **вашем Ubuntu VPS**. GitHub хранит код и запускает удалённое развёртывание; GitHub Actions сам по себе не является постоянно работающим VPN-сервером.

## Требования
- VPS с Ubuntu 22.04/24.04, публичным IPv4 и открытым TCP-портом 443.
- Root-доступ (или пользователь с sudo).
- В GitHub → Settings → Secrets and variables → Actions добавьте:
  - `VPN_HOST` — IP/домен VPS
  - `VPN_USER` — SSH-пользователь (обычно root)
  - `VPN_SSH_KEY` — приватный SSH-ключ целиком
  - необязательно `VPN_SSH_PORT` — SSH-порт (по умолчанию 22)

## Развёртывание
В репозитории откройте Actions → **Deploy NovaVPN server** → Run workflow. В логах шага Deploy будет напечатана ссылка `vless://...`. Импортируйте её в NovaVPN как одну ссылку сервера.

## Ручная установка
Скопируйте `deploy.sh` на Ubuntu VPS и выполните:
```bash
sudo bash deploy.sh
```
Скрипт установит sing-box, создаст UUID и ключи REALITY, включит TCP/443 и выведет персональную VLESS-ссылку.

## Важно
- Без VPS и SSH-доступа создать работающий публичный VPN-сервер только средствами GitHub нельзя.
- Не коммитьте приватный SSH-ключ, UUID или готовую клиентскую ссылку в репозиторий.
- Это минимальная конфигурация одного пользователя; для эксплуатации добавьте резервное копирование, обновления и мониторинг.
