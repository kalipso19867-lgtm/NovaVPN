# NovaVPN (Android / WireGuard)

Исходный Android-проект NovaVPN. Протокол: WireGuard. Приложение принимает WireGuard-конфигурацию `.conf` через системный выбор файла и подключает её через официальный WireGuard Tunnel Library.

## Важно
- Репозиторий содержит приложение-клиент, а не арендованный VPN-сервер.
- Конфигурация сервера/приватный ключ в репозиторий не включены. Не публикуйте их в GitHub.
- Ранее присланный QR/URL был распознан как Booі VPN subscription; это не подтверждённый WireGuard `.conf`. Поэтому он не встроен. Нужен экспорт Wireguard `.conf` от провайдера либо свой WireGuard-сервер.

## Сборка APK
Откройте репозиторий в Android Studio и дождитесь синхронизации Gradle. Затем Build → Build Bundle(s) / APK(s) → Build APK(s). APK появится в `app/build/outputs/apk/debug/`.

## Сборка в GitHub Actions
Откройте вкладку Actions и запустите workflow **Android Debug APK**. После завершения скачайте артефакт `NovaVPN-debug-apk`.

## Требования
Android Studio, JDK 17, Android SDK 35. Минимальная версия Android — 8.0 (API 26).

## Использование
1. Установите APK.
2. Нажмите «Импортировать .conf» и выберите WireGuard-конфигурацию.
3. Нажмите «Подключить» и подтвердите системный запрос Android на VPN.
4. Для отключения нажмите «Отключить».

Проект — начальная сборка; перед публикацией проверьте подключение на своём сервере и настройте подпись релизной версии.
