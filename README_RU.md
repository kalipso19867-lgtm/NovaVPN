# NovaVPN — sing-box Android

Сборка NovaVPN на основе Android-клиента sing-box. Поддерживаемые форматы зависят от ядра sing-box и реализации клиента: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard.

## Сборка
GitHub Actions → workflow `NovaVPN sing-box Android APK`. После успешного завершения скачайте `NovaVPN-singbox-debug-apk`.

## Подписка
Добавьте URL подписки в приложении. Приватные URL и ключи не публикуются в репозитории.

## Важно
Успешная компиляция не подтверждает доступность конкретного сервера. Проверьте импорт подписки и соединение на устройстве.
